## Программа и итоговая работа

**Статус:** не начат.

**Цель:** довести основной проект до использования и подготовиться к поиску работы.

| Недели | Основное содержание |
|---|---|
| 1–4 | Evals, регрессионные проверки, CI/CD, логи, трассировка, мониторинг, нагрузка, очереди, кеширование, стоимость, безопасность и prompt injection |
| 5–7 | Transformer на концептуальном уровне, основы PyTorch, локальные модели, память и квантование, различия промптинга/RAG/fine-tuning, знакомство с LoRA |
| 8–10 | Пользовательское тестирование, исправления, документация, архитектурный разбор и портфолио |
| 11–12 | Пробные интервью, отклики и защита итогового проекта |

Дообучение делать при наличии подходящих данных и вычислительных ресурсов. В условиях нехватки времени приоритет — RAG, качество и эксплуатация.

**Субботние темы:** браузерный рендеринг, HTTP, доступность, производительность, CSR/SSR/SSG, hydration, миграции, monorepo и применимость микрофронтендов. Повторение алгоритмов, базовая динамика по готовности и подготовка к интервью.

**Итоговая работа:** законченный ИИ-сервис с инструкцией запуска, проверками качества, мониторингом, учётом расходов и описанием ограничений.

**Защита:** объяснить задачу, архитектуру, выбор модели, эксперименты, качество, стоимость, безопасность и слабые места решения.

## Правила обновления

1. Перед занятием прочитать общий план и этот файл; перед редактированием перечитать актуальные версии обоих.
2. Общий план — основной источник текущего состояния. В этот файл копировать относящиеся к S4 записи занятий, прогресс, домашние работы и решения.
3. После занятия обновлять оба файла в одном наборе изменений. Использовать одинаковый ID занятия; при исправлении обновлять существующую запись в обоих журналах, не создавать дубликат.
4. Ссылки на материалы корректировать относительно расположения файла: из общего плана — `../S4/…`, из этого файла — `../…`.
5. При расхождениях сверить фактическую работу и историю изменений. Не отмечать тему освоенной только по календарю или наличию материалов.
6. При завершении семестра скопировать итог и передачу контекста в общий план. Файл `docs/ШАБЛОН_УЧЕБНОГО_ПЛАНА.md` в корне репозитория не заполнять личным прогрессом.
