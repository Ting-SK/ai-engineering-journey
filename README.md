# AI Engineering Journey

Личный репозиторий обучения и практики на пути из Senior Frontend Developer в **AI / LLM Application Engineer** — разработчика приложений на основе искусственного интеллекта и больших языковых моделей.

Здесь будут собраны учебный план, конспекты, упражнения, домашние работы и проекты. Репозиторий позволяет сохранять результаты занятий, отслеживать развитие навыков через историю Git и постепенно собирать портфолио.

**Основной документ — [УЧЕБНЫЙ_ПЛАН.md](./docs/УЧЕБНЫЙ_ПЛАН.md).** В нём находятся подробная программа, расписание, актуальная точка обучения, журнал занятий и следующие шаги.

## Цель

Научиться самостоятельно проектировать, создавать, проверять и развёртывать ИИ-приложения: от серверной части на Python до интеграции LLM, работы с документами и оценки качества ответов.

Исходная база — коммерческая React/JavaScript-разработка с 2021 года и небольшой опыт бэкенда. Основной новый язык — Python. Параллельно продолжается изучение JavaScript, TypeScript, React, архитектуры, браузера и алгоритмов.

## Программа

Обучение рассчитано ориентировочно на год: четыре семестра по 12 учебных недель и время на отдых и резерв. Нагрузка — около девяти часов в неделю, совмещённых с работой.

| Семестр | Направление |
|---|---|
| S1 | Основы ИИ и LLM, Python, серверная разработка и базы данных |
| S2 | Основы машинного обучения, API языковых моделей и оценка качества |
| S3 | RAG — ответы с опорой на найденные документы; инструменты и агенты |
| S4 | Эксплуатация, мониторинг, безопасность и подготовка проектов для портфолио |

Сроки и содержание уточняются по фактическим результатам. Подробности и текущий статус ведутся в общем учебном плане.

## Организация репозитория

Материалы группируются по семестрам, внутри семестра — по темам и проектам. Общий план и шаблон находятся в корневой папке `docs/`. Папки S1–S4 содержат свои `docs/` с файлами `ПЛАН_СЕМЕСТРА_S1.md`–`ПЛАН_СЕМЕСТРА_S4.md`. Папки тем и проектов в примере ниже добавляются по мере выполнения работ.

```text
ai-engineering-journey/
├── README.md
├── docs/
│   ├── УЧЕБНЫЙ_ПЛАН.md
│   └── ШАБЛОН_УЧЕБНОГО_ПЛАНА.md
├── S1/
│   ├── docs/
│   │   └── ПЛАН_СЕМЕСТРА_S1.md
│   ├── 01-llm-basics/
│   │   ├── notes.md
│   │   ├── exercises/
│   │   └── homework/
│   ├── 02-python/
│   ├── 03-backend/
│   ├── frontend/
│   └── projects/
│       └── document-service/
├── S2/
│   └── docs/
│       └── ПЛАН_СЕМЕСТРА_S2.md
├── S3/
│   └── docs/
│       └── ПЛАН_СЕМЕСТРА_S3.md
└── S4/
    └── docs/
        └── ПЛАН_СЕМЕСТРА_S4.md
```

- `notes.md` — объяснения своими словами, примеры, термины и выводы.
- `exercises/` — упражнения с занятий и небольшие эксперименты.
- `homework/` — условия домашних работ, решения и исправления после проверки.
- `frontend/` — параллельная практика по фронтенду и алгоритмам.
- `projects/` — самостоятельные приложения с собственными инструкциями запуска и проверками.

Общий план остаётся основным источником актуального прогресса. В планы семестров копируются соответствующие записи занятий, домашние работы и результаты; оба файла обновляются вместе с одинаковыми ID занятий. Это правило ведения документов, а не автоматическая синхронизация. Подробные материалы хранятся рядом с соответствующими заданиями и кодом.

## Как проходит обучение

Занятия проходят с ИИ-ассистентом: краткое объяснение, самостоятельная попытка, обратная связь и закрепление. Новые понятия разбираются по-русски, при необходимости используются английские первоисточники.

Работа над каждой темой включает:

1. Изучение теории и разбор примеров.
2. Самостоятельное выполнение упражнения или части проекта.
3. Проверку результата, разбор ошибок и исправления.
4. Объяснение решения своими словами и фиксацию выводов.
5. Обновление журнала в учебном плане, коммит и отправку изменений в GitHub.

В прогрессе различаются прочитанный материал, решение с помощью и самостоятельное выполнение. Наличие конспекта или сгенерированного кода само по себе не означает освоение темы.

## Практические результаты

По мере обучения планируется создать сервис обработки документов, приложение для извлечения структурированных данных и помощника по документации с источниками и контролируемыми действиями.

Каждый проект будет содержать описание задачи, инструкцию запуска, объяснение архитектуры, проверки и известные ограничения. Зависимости и команды запуска указываются в README конкретного проекта — общей команды запуска для всего учебного репозитория нет.

Репозиторий пополняется постепенно. Завершённость тем и проектов определяется результатами практики и отражается в [учебном плане](./docs/УЧЕБНЫЙ_ПЛАН.md).

## Как повторить этот маршрут

Используйте [шаблон учебного плана](./docs/ШАБЛОН_УЧЕБНОГО_ПЛАНА.md): в нём сохранены четыре семестра, практические проекты, критерии зачёта и правила ведения журнала, а личные данные и прогресс заменены полями для заполнения.

1. Создайте собственный учебный репозиторий или форк этого репозитория.
2. Скопируйте шаблон в свой `docs/УЧЕБНЫЙ_ПЛАН.md`, предварительно сохранив существующий файл, если он вам нужен.
3. Укажите свой опыт, дату старта, часовой пояс и доступную нагрузку.
4. Адаптируйте первую неделю и ведите собственный журнал занятий.

Маршрут рассчитан на человека с опытом разработки. При другой исходной подготовке измените темп и добавьте необходимые вводные темы. Шаблон остаётся заготовкой; текущий прогресс ведётся в вашей рабочей копии.
