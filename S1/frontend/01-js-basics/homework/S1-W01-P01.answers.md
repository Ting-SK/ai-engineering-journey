## 2. Области видимости

```js
const level = 1;
function show() {
  console.log(level); // A в лексическом окружении функции данная переменная не найдена, тогда будет обращение во внешнее окружение, где будет найдена const level=1 - выведется 1
  if (true) {
    let level = 2;
    var label = 'local';
    console.log(level); // B условие в любом случае выполнится, в окружении блока есть переменная аналогичная переменной во внешнем окружении, происходит shadowing будет выводится значение let level=2 - выведется 2
  }
  console.log(label); // C так как в условии была объявлена переменная через var - она инициализируется в окружении функции, и так как нет других переменных будет вывдеено значение 'local'
}
show();
console.log(label); // D будет ошибка, так как var label = 'local' доступна только в окружении функции
```

Что изменится, если перенести B перед let level = 2? Объясни, какие строки успеют выполниться.
- строка А успеет выполниться, на строке B появится reference error так как  let level попадет в TDZ и не инициализируется при выполнении
