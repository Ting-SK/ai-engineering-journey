## Области видимости

Ожидания A = 1, B = 2, C = 'local', D = ReferenceError верны и подтверждены запуском ассистента.

При переносе B перед let level = 2 сначала выводится 1 на A, затем B вызывает ReferenceError. C и D не выполняются: необработанное исключение прерывает выполнение. Пользователь правильно определил A и ошибку B.

Уточнения терминов:
- Локальная level находится в TDZ с момента входа в блок до инициализации, а не «попадает» в неё из-за чтения. Чтение в этот период вызывает ошибку.
- Для var label при входе в функцию создаётся привязка со значением undefined; строка var label = 'local' затем присваивает 'local'. Отсутствие других переменных не является причиной результата C.
