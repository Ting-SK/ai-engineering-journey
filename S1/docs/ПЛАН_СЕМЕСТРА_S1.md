## Программа и итоговая работа

**Статус:** не начат.

**Цель:** освоить базовые понятия ИИ и научиться самостоятельно создавать серверные приложения на Python.

| Недели | Основное содержание |
|---|---|
| 1–3 | Модель, LLM, обучение и инференс, токены, контекст, промпты, галлюцинации, агенты. Постановка задач, передача контекста, проверка ответов и применение ИИ в своей работе |
| 4–7 | Python: коллекции, функции, модули, классы, исключения, типизация, окружения, файлы, JSON, HTTP-запросы, асинхронность и pytest |
| 8–10 | FastAPI, валидация, SQL/PostgreSQL, миграции, обработка файлов, основы авторизации, Docker и развёртывание |
| 11–12 | Закрепление и итоговый проект |

**Субботние темы:** JS — типы, преобразования, scope, hoisting, TDZ, замыкания, this, прототипы, event loop и promises. Алгоритмы — сложность, массивы, строки, хеш-таблицы.

**Итоговая работа:** сервис загрузки и обработки документов с базой данных и небольшим React-интерфейсом. Он может стать основой следующих проектов.

**Зачёт:** самостоятельно запустить приложение, объяснить его устройство, написать проверку и исправить предложенную ошибку.

**Источники:**

## Правила обновления

1. Перед занятием прочитать общий план и этот файл; перед редактированием перечитать актуальные версии обоих.
2. Общий план — основной источник текущего состояния. В этот файл копировать относящиеся к S1 записи занятий, прогресс, домашние работы и решения.
3. После занятия обновлять оба файла в одном наборе изменений. Использовать одинаковый ID занятия; при исправлении обновлять существующую запись в обоих журналах, не создавать дубликат.
4. Ссылки на материалы корректировать относительно расположения файла: из общего плана — `../S1/…`, из этого файла — `../…`.
5. При расхождениях сверить фактическую работу и историю изменений. Не отмечать тему освоенной только по календарю или наличию материалов.
