# Постановка задачи модели и проверка ответа

S1-W01-P04 · 27 октября 2026. Конспект фактически пройденного материала.

## Четыре составляющие запроса

| Часть | Назначение |
|---|---|
| Задача | Что сделать с данными |
| Исходные данные | На чём основывать результат |
| Формат | Как представить ответ |
| Критерии и ограничения | Как проверить результат и какие выводы недопустимы |

Задача должна соответствовать доступным сведениям. По одному баг-репорту без кода и логов можно подготовить карточку и следующий шаг диагностики, но нельзя достоверно назвать конкретную причину и строку кода.

Сокращая отчёт, не теряем важные наблюдения: действия, поведение UI, сообщение об ошибке, состояние после обновления страницы, запрос, статус, окружение, время. Ожидаемый результат, выведенный из контекста, обозначаем как предполагаемый.

## Наблюдение, гипотеза и проверка

«После обновления страницы видно старое имя» — наблюдение. «Новое имя не записалось в базу» — гипотеза. Для её проверки нужны сведения о сохранении и последующем чтении. Старое имя может иметь и другие причины; возможность кеша не является установленной причиной.

Подтверждено — есть поддерживающие данные. Опровергнуто — есть противоречащие данные. Не установлено — информации недостаточно для подтверждения или опровержения. Неподтверждённое утверждение не обязательно ложно и не имеет отношения к тому, произойдёт ли событие когда-нибудь в будущем.

## Неизвестное не равно отсутствующему

«Тела ответа нет» неоднозначно: ответ мог быть пустым либо его содержимое не приложили. Точная карточка сохраняет неоднозначность и задаёт вопрос: проверено ли пустое тело или оно не предоставлено?

Преподаватель сначала записал «не предоставлено», затем уточнил, что это тоже интерпретация исходной фразы. Полезно проверять даже аккуратно звучащие пересказы.

HTTP 500 сообщает о неожиданном условии на сервере, помешавшем выполнению запроса. По статусу нельзя определить причину или наличие непустого тела. Содержимое ответа может иметь нулевую длину: [RFC 9110, 6.4.1](https://www.rfc-editor.org/rfc/rfc9110.html#section-6.4.1), [определение 500](https://www.rfc-editor.org/rfc/rfc9110.html#section-15.6.1). Источник проверен на занятии.

Chrome на ноутбуке не означает все версии Chrome или все окружения. Версия, ОС и воспроизводимость на других устройствах не указаны.

## Проверка качества

1. Полнота: сохранены существенные наблюдения.
2. Достоверность: нет придуманных причин, файлов, версий и фактов.
3. Неопределённость: неизвестное и предположения обозначены явно.
4. Формат: присутствуют запрошенные разделы.
5. Полезность: предложен конкретный способ получить недостающие сведения.

Семь правильных заголовков не компенсируют выдуманную причину. Такой ответ нельзя принимать: неподтверждённый вывод нужно убрать или явно оформить как гипотезу, если гипотезы разрешены задачей. Для нашей карточки — «причина не установлена» и следующий шаг диагностики.

Цикл работы: задача → запрос → ответ → сверка с исходными данными → уточнение запроса → повторная проверка. Хороший промпт снижает риск ошибки, но не гарантирует достоверности.

## Практика и результат

Ассистент сформировал полную карточку по запросу пользователя. Пользователь верно отказался делать вывод о записи в БД по старому имени в UI и обобщать ошибку на все версии браузера.

На намеренно ошибочном ответе пользователь выделил подтверждённый запрос PATCH /api/profile со статусом 500. Утверждения про все версии Chrome, недоступную БД, пустое тело и profileService.ts были неподтверждёнными, а не доказанно ложными.

Ошибочные объяснения: «500 исключает пустое тело» и «неподтверждённое означает, что это не случится никогда». Исправлены после объяснений. Финальный ответ пользователя: состояние базы «не установленное, нет данных по БД в тот момент времени» — верно.

Форматирование запроса выполнено пользователем после обратной связи; последние ограничения сформулированы им самостоятельно. Различие неизвестного и ложного требует отсроченной проверки. Пара завершена; практика на полном, неполном и противоречивом отчётах остаётся на следующую лабораторную.
