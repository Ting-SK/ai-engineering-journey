# Домашняя работа S1-W01-P03

Статус: назначена, не выполнена. Ориентир: 10–15 минут в рамках учебного времени. Можно выполнить в начале следующего занятия; обязательной работы в дни отдыха нет.

Ответы записывай отдельно в S1-W01-P03.answers.md рядом с заданием. Условие не переписывай; достаточно номера и своего объяснения. После сдачи преподаватель создаст S1-W01-P03.review.md.

## 1. Объясни механизм

Для каждого случая укажи: меняются ли параметры модели, откуда берётся информация и что именно происходит. В одном случае может быть несколько этапов.

А. Приложение сохранило адрес доставки пользователя в базе и добавило его в новый запрос к модели.

Б. Инженер показал модели много примеров обращений клиентов и с помощью алгоритма обучения обновил её веса.

В. Модель неправильно описала функцию. В следующий запрос добавили её реализацию, и модель исправила описание. Обновление весов не запускали.

Г. Пользователь открыл новый разговор. Приложение передало только его вопрос, без предыдущей истории и сохранённых настроек. Может ли модель опереться на особую договорённость из прошлого разговора? Почему?

## 2. Короткое объяснение коллеге

В 3–5 предложениях объясни различие между параметрами, токенами и контекстом. Затем назови две причины, по которым модель может ошибиться даже при корректном входном тексте.

Критерий: различаешь вычисления и обновление параметров; изменение ответа не считаешь доказательством обучения; отделяешь внешнее хранилище от реально переданного контекста. Сначала своя попытка без копирования конспекта, затем можно свериться и явно отметить исправления.
